コンテンツが伸び悩む理由

コンテンツ戦略を停滞させる3つの失敗

コンテンツ診断を行うと、ほとんどの場合3つの問題が見つかります。どれも記事を増やすことでは解決しません。

仮説のないまま本数だけが増える

毎週のように公開していても、そのブログが何のためにあるのかを説明できないチームは少なくありません。どのテーマで第一想起を取りにいくのか、なぜ自社がそれを語れるのかという仮説がなければ、企画は毎回ゼロから議論になり、蓄積は無関係な記事の山に見えてしまいます。コンテンツ戦略とコンテンツマーケティングが分かれるのはここです。戦略は、誰かが1行書き始める前に、何についてのプログラムなのかを決めます。

1

テーマに担当者がいない

オウンドメディアの戦略は、クラスターが全員のものになった時点で静かに崩れます。枠はその週に手の空いた人で埋まり、深さは蓄積せず、購買判断を動かすはずの記事だけが後回しになります。1枠ごとに担当者と形式を決めたカレンダーは、公開される中身そのものを変えます。

2

やめる判断が一度もされない

コンテンツのプログラムには、やめる判断がほとんど含まれていません。何年も前に成果を生まなくなったページが、新しい記事と検索順位を奪い合い、クロールの予算を使い、読んだ人を誤解させ続けます。統合する、削除すると決めることも、公開すると決めることと同じだけ戦略的な成果物です。

お引き受けするコンテンツ戦略の作業

固定料金と担当者が決まった3つの成果物に加えて、隣接するメニューとの線引きも明示します。

サイトのコンテンツ診断

公開中のコンテンツをページ単位で棚卸しし、成果と鮮度で評価して、URL ごとに1つの判断を出します。これが入口の作業であり、このページの他のすべての入力になります。

  • + URL ごとの流入・コンバージョン・最終更新日
  • + 全ページへの判断（残す・更新・統合・削除）
  • + 共食いしているページの組み合わせと、残すページの指定
  • + 工数と期待効果の順に並べた優先修正リスト
  • + 対象言語が複数ある場合は市場ごとに診断を実施

コンテンツ戦略の策定

コンテンツ戦略の会社が本来求められている判断そのものです。何で第一想起を取るのか、誰に向けて、どの形式で、どうやって成否を知るのか。すべてのクラスターに着地ページと指標を付けてお渡しします。

  • + 市場ごとのテーマ仮説と読者の定義
  • + ファネル段階と着地ページに対応づけたクラスター
  • + クラスターごとの形式と公開頻度の決定
  • + クラスターごとの指標を明記した計測計画
  • + ライティングのメニュー料金で見積もれる制作計画

コンテンツ企画と公開カレンダー

記事の企画を代行する会社が最後に渡すべきものです。担当者、形式、企画書、リライト枠が入った日付入りのカレンダーを、チームがすでに使っている計画ツール上でお渡しします。

  • + チャネルごとの日付入り公開カレンダー
  • + 全枠への担当者と形式の割り当て
  • + 制作に引き渡せる企画書の待ち行列
  • + 新規記事と並ぶ既存 URL のリライト枠
  • + 同じクラスターに合わせた SNS とメールの配信頻度

このメニューの対象外

コンテンツのギャップ分析と競合分析は、SEO調査のメニューで料金と納品を定めています。同じ作業がカートに二重に入らないようにするためです。執筆、リライト、翻訳はそれぞれ独立した制作メニューで、料金も公開しています。

  • + コンテンツのギャップ分析と競合コンテンツ分析：SEO調査のメニュー
  • + キーワード選定と検索需要のクラスタリング：SEO調査のメニュー
  • + ページ単位の最適化と記事の企画書：内部対策のメニュー
  • + 記事・LP・商品コピーの制作：ライティングの各メニュー
  • + プログラム全体としてのコンテンツマーケティングの戦略：コンテンツサービスのページ

当社のコンテンツ戦略が違うところ

範囲を区切った診断、説明できる仮説、そして価格の入った制作発注で終わる計画です。

意見より先に根拠

すべての提案は診断表のどこかの行までたどれます。テーマを提案する前に、解析データ、Search Console、実際の検索結果、そして御社の商談メモを読みます。だからコンテンツ戦略の担当者は、御社のデータで議論できます。根拠が薄いところは、診断表で明示します。

  • すべてのテーマ提案は診断表の行までたどれる
  • 解析データ・Search Console・実際の検索結果を合わせて読む
  • 根拠の薄い箇所は診断表で明示する

翻訳版ではなく、市場ごとのカレンダー

多言語・海外・グローバルのプログラムは、ドイツ語のカレンダーが英語のカレンダーのドイツ語版になった時点で失敗します。テーマの仮説は市場ごとに、その国の需要と競合から組み立て、どのクラスターを共通にしてどれを市場固有にするかを意図して決めます。海外での BtoB のコンテンツ戦略は、この区別で成否が分かれます。

  • テーマ仮説は市場ごとに現地の需要から構築
  • 共通クラスターと市場固有クラスターを明示的に決定
  • 対象言語と対象国の追加は範囲の決まった加算として提示

価格の入った発注で終わる戦略

計画の最後のページは制作の発注書です。各クラスターに形式、分量、そして公開しているライティングメニューの料金が入っているため、二度目の見積もり工程なしで、納品したその日に予算の1行として承認できます。

  • 戦略に費用入りの制作計画を添付
  • 各クラスターを公開料金で見積もり
  • 二度目の見積もり工程なしで制作へ引き渡し

対応範囲、料金、納品についての率直なご回答です。

コンテンツ診断の費用はいくらですか？

50ページのコンテンツ診断は $500、200ページは $1,000、500ページは $1,800 です。2,000ページを超える場合は個別にお見積もりします。掲載料金は英語の中核部分と主要1か国が対象で、対象言語が1つ増えるごとに基本料金の60%、対象国が1つ増えるごとに40%が加算されます。

コンテンツ診断にはどのくらい時間がかかりますか？

S（50ページ）は5営業日、M（200ページ）は8営業日、L（500ページ）は12営業日です。戦略の策定は診断のご承認後2〜3週間、編集カレンダーは戦略の完成から1週間以内にお渡しします。

コンテンツ戦略には何が含まれますか？

市場ごとのテーマ仮説と読者の定義、ファネル段階と着地ページに対応づけたテーマクラスター、形式と公開頻度の決定、各クラスターの評価指標を明記した計測計画、そして費用入りの制作計画です。担当者・形式・企画書が入った日付入りの編集カレンダーは、$400 からの別作業になります。

コンテンツ戦略とコンテンツマーケティングはどう違いますか？

コンテンツ戦略は、何を、誰に、どの順番で公開し、成否をどう測るかを決めます。コンテンツマーケティングは、それを制作し、届け、広げていく継続的な取り組みです。このメニューは戦略側の半分で、計画で終わる一度きりのご支援です。制作と配信まで含むコンテンツマーケティングの戦略をお探しの場合は、コンテンツサービスのページからご覧ください。

コンテンツのギャップ分析や競合分析もお願いできますか？

承ります。どちらも SEO調査のメニューで $400 から料金と納品を定めており、同じ作業が1つの注文に二度現れないようにしています。診断とは相性がよく、診断は手持ちのページをどうするかを、ギャップ分析と競合分析は足りないページがどれかを教えてくれます。

コンテンツ診断は自社でもできますか？

できますし、手順は秘密でもありません。全 URL を書き出し、流入とコンバージョンのデータを結合し、最終更新日を足して、1行に1つの判断を必ず出すだけです。多くのチームに足りないのは、削除する覚悟です。外部に依頼する価値は、ページを生かしておく利害を持たない第三者の判断が手に入ることにあります。

必要なのは戦略の担当者ですか、ライターですか？

戦略の担当者は、どのページが存在すべきで、何で評価するかを決めます。ライターはそれを書きます。何を公開するか決まっていて文章だけが必要なら、ライティングのメニューへ直接お進みください。公開は続いているのに成果を示せない状態なら、まずこのページの診断から始めてください。

コンテンツはどのくらいの頻度で診断すべきですか？

多くのサイトでは年に1回、あるいは前提が変わる出来事のあとです。サイト移行、ブランド刷新、新しい市場への参入、流入の急減などが該当します。月に20本以上公開する動きの速いサイトでは、直近に公開した分だけを対象に半年ごとの軽い点検も有効です。オウンドメディアの立ち上げ直後も、最初の3か月で一度見直すと方向のずれを早く直せます。
